# 🛒 SmartMart AI

## Cloud-Based Retail Intelligence & Demand Forecasting Platform

SmartMart AI is an end-to-end retail analytics platform that combines Data Engineering, AWS Cloud, Machine Learning, and Power BI to help businesses transform raw sales data into actionable insights and sales forecasts.

## 🚀 Tech Stack

- Python
- AWS
- SQL
- Power BI
- Machine Learning
- Git & GitHub
